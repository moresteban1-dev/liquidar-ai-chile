# Checklist de Auditoría

Usa este sistema de puntuación para evaluar landing pages existentes.

## Sistema de Puntuación (Total: 100 Puntos)

| Categoría | Puntos Max | Qué buscar |
| :--- | :--- | :--- |
| **Sección Hero** | **20** | ¿Queda claro qué es en 5 segundos? ¿Hay CTA claro? ¿Imagen relevante? |
| **Propuesta de Valor** | **15** | ¿Se entiende el beneficio único? ¿Diferenciación clara? |
| **Prueba Social** | **15** | ¿Testimonios reales? ¿Logos de clientes? ¿Casos de éxito? |
| **Optimización CTA** | **15** | ¿Contrastan? ¿Tienen texto de acción? ¿Están repetidos lógicamente? |
| **Calidad del Copy** | **15** | ¿Habla al usuario ("Tú")? ¿Enfocado en beneficios? ¿Sin jerga? |
| **Diseño y UX** | **10** | ¿Legible? ¿Jerarquía visual? ¿Responsive impecable? |
| **Rendimiento Técnico** | **10** | ¿Carga rápido? ¿Funcionan todos los links? ¿SEO básico? |
